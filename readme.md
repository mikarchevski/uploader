#  Инструкция по локальному развёртыванию проекта Uploader

Данная инструкция описывает пошаговый процесс настройки и запуска проекта mikarchevski/uploader на вашем локальном компьютере. Сохраните этот текст как `INSTALL.md`.

##  Системные требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)
- git (для клонирования репозитория)

##  Пошаговая установка

### 1. Клонирование репозитория
Откройте терминал и выполните следующие команды для скачивания кода и перехода в директорию:
```bash
git clone https://github.com/mikarchevski/uploader.git
cd uploader
```

### 2. Создание виртуального окружения
Изоляция зависимостей предотвратит конфликты с другими Python-проектами.
```bash
# Для Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Для Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
Установите все необходимые библиотеки из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Сгенерируйте криптографически стойкий ключ для Flask, выполнив встроенный скрипт:
```bash
python3 generate_secret_key.py
```
>  Скрипт выведет уникальный ключ и предложит автоматически создать файл `.env`. Вы можете согласиться (введя `y`) или создать файл вручную.

Если вы создаёте файл `.env` вручную, создайте его в корневой папке проекта и используйте следующий шаблон:
```env
# === БЕЗОПАСНОСТЬ ===
SECRET_KEY=ваш_уникальный_секретный_ключ

# Токен для обхода лимитов (опционально). При добавленном токене лимиты будут как для тестового окружения
E2E_BYPASS_TOKEN=my_super_secret_local_token_123

# === НАСТРОЙКИ ПРИЛОЖЕНИЯ ===
FLASK_ENV=development
FLASK_DEBUG=1

# === ПУТИ К ФАЙЛАМ И БАЗЕ ДАННЫХ ===
UPLOAD_FOLDER=./uploads
DB_PATH=./data/uploads.db
PREVIEW_CACHE_FOLDER=./data/previews
```

### 5. Создание необходимых директорий
Создайте папки для загружаемых файлов, базы данных и кэша превью, чтобы избежать ошибок прав доступа:
```bash
mkdir -p uploads data/previews
```

### 6. Запуск приложения
Для запуска в режиме разработки используйте скрипт `run_dev.py`:
```bash
python3 run_dev.py
```

##  Проверка работы
После успешного запуска в терминале появится сообщение о старте сервера. Откройте браузер и перейдите по адресу:
http://127.0.0.1:5000 (или http://localhost:5000)

##  Возможные проблемы и решения
- **ModuleNotFoundError**: Убедитесь, что виртуальное окружение активировано и вы выполнили `pip install -r requirements.txt`.
- **Permission denied**: Проверьте, что у вашего пользователя есть права на запись в папки `./uploads` и `./data`.
- **Address already in use**: Завершите процесс, использующий порт 5000, или измените порт в настройках запуска.
- **База данных не создаётся**: Убедитесь, что папка `./data` существует и путь `DB_PATH` в `.env` указан верно.
